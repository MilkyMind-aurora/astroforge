# 吉祥物「星仔」设计规范（mascot spec v1）

> 风格参考：[blessonism/grok-icon-study](https://github.com/blessonism/grok-icon-study)（Grok Bot 角色动效学习复刻）。
> **版权边界（重要）**：仅借鉴其造型语言——blob 轮廓、多边形眼睛、状态机驱动帧动效、弹簧缓动；**星仔形象为 AstroForge 原创**（星形 blob + 锻造元素），不复制/再分发 xAI 的几何数据、贴图与商标素材。素材归属声明随软著/开源材料同步。

## 1. 形象设定

星仔是一颗在数字熔炉里值班的小星星：主体为一团圆润的五角 blob（五个短圆角的星形凸起），通体暗夜蓝描边、星尘紫填充，胸口一枚熔金色的火花渣。它拿着一把比自己还大的迷你锻造锤，坚信「所有混乱的原始数据，都值得被锻造成一颗干净的文档恒星」。话不多，但每句都带天文冷笑话。

- 配色：主体 `#8B7CF6`（星尘紫）、描边 `#0B0E1A`（深空黑）、火花 `#FFB74D`（熔金）、眼白 `#F5F3FF`
- 眼睛：多边形（六边形略斜）纯黑眼片，参考 Grok Bot 的几何眼设计语言；情绪由眼片形状与位置表达
- 身形：blob 主体可轻微果冻抖动（弹簧动效），锤子是唯一刚性部件

## 3. 台词库（触发事件 → 俏皮话）

| 触发事件 | 台词 |
| --- | --- |
| 启动问候 | 「熔炉点火完毕，今天也把混沌锻造成秩序。」 / 「Sidereal Core 上线——恒星已进入主序带。」 / 「星仔报到，数据氢准备好聚变了吗？」 |
| 空闲随机出现 | 「嘘……猎户座那边比我这边还安静。」 / 「闲置也是蓄能，恒星不闪光的时候在攒核聚变。」 / 「要不要喂我一点 PDF？」 |
| 任务完成 | 「锻造完成！这批数据已经烧掉三层杂质。」 / 「交付✦ 星表上又多了一颗干净文档。」 / 「核聚变结束，输出比输入亮多了。」 |
| 任务失败 | 「呃……有颗氢原子没听话。看看日志里谁在捣乱。」 / 「熔炉打个嗝而已，重试一下就好。」 / 「引力坍缩失败了，建议检查参数引力场。」 |
| AI 降级兜底 | 「AI 走神了，已用快捷模式执行，建议检查参数。」 / 「我打了个盹，靠肌肉记忆帮你跑完了——参数最好亲自看一眼。」 |
| 深夜彩蛋（22 点后） | 「银河系此刻也很忙，但它没有暂停键。少熬夜，程序员。」 / 「凌晨的终端和望远镜一样，都能看见别人看不见的东西。」 |

## 4. TUI 集成建议（Textual）

1. **状态栏旁挂载**：Footer 左侧显示迷你帧（单行 ASCII，idle/sleeping 二帧轮换），`settings.system.mascot_enabled: true` 控制，关闭则完全隐藏
2. **任务完成通知**：Modal 通知右上角弹出 happy 帧 + 台词库随机一条，3s 自动消失；错误时 error 帧 + 对应建议台词
3. **空态页彩蛋**：首页无任务历史时显示 idle 帧引导「喂我一点 PDF」，避免空屏冷启动感

## 5. Flutter 集成建议

1. **闲置浮窗**：应用空闲 > 10 分钟后右下角浮出 sleeping→idle 动画窗（可点击召唤 AI 抽屉），`mascot_enabled` 同源开关
2. **庆祝动画**：任务完成时使用像素帧序列（对应 ASCII 帧 `>`→`‿`→`▲` 的矢量版）做 1.2s 弹簧缩放入场，呼应 Grok Bot 的弹簧动效语言
3. **错误页彩蛋**：连接失败/任务失败页放置 error 帧起手，配台词库中「任务失败」组随机一条，降低报错挫败感

## 6. 帧素材落地方式

- TUI：直接用本文件 ASCII 帧常量（Phase 8.3 落地为 `tui/tui/ui/mascot.py`）
- Flutter：本文件 ASCII 帧为蓝图，矢量重绘为 5 帧序列（idle×2/happy/error/sleeping），以 SVG/自绘 Canvas 入库（Phase 8.3.1），不引入位图素材
