# MF4 验收录屏执行指引与记录表（walkthrough）

> 地位：《前端优化方案V1-星空版》V1.1-6「MF4 验收新增三条」的留档页。三条录屏**必须真人真机执行**（自动化只能验证门禁与截图，无法替代人工操作录屏）——本页提供逐条执行脚本与结果记录表；执行后把「结果」列从 ⬜ 改 ✅ 并回填产物路径，随一次普通提交入库。
> 环境前提：Windows 11 开发机；录屏工具任选（OBS / Xbox Game Bar Win+G / 其余）；录屏前清空 `data/logs/` 便于对照。

## 录屏一：断网杀服务冷启动（含拉起失败分支）

1. 确保 Sidereal Core 未运行：`curl -s http://127.0.0.1:8420/api/v1/system/health` 应无响应（在跑则用界面「停止」或 `scripts\stop_service` 语义停掉）。
2. 启动 Flutter 端（`scripts\start_app.bat` 或 IDE），开始录屏。
3. 剧本：①连接引导页出现（星仔 sleeping + 命令卡）；②点「一键拉起服务」→ 阶段化反馈（激活环境→端口监听→数据库握手→就绪，持续轮询至 60s）；③**失败分支**：录制期间把 `ASTROFORGE_PG_PASSWORD` 临时设错再拉起一次 → 引导页应显示 stderr 尾行诊断卡 + 「复制诊断」可用；④恢复正常密码、服务就绪后进入主界面。停止录屏。
4. 检查点：等待期品牌元素（星野/星仔）不消失；失败分支用户能看到「为什么失败」而非无限跑圈。

|---|---|---|
| 成功路径（阶段化反馈→就绪） | ⬜ | docs/design/walkthrough/ |
| 失败分支（诊断卡+复制诊断） | ⬜ | 同上 |

## 录屏二：引擎休眠时首页首屏（输入条降级+唤醒）

1. 启动服务核心与 Flutter 端；等待 AI 引擎闲置自动卸载（>5 分钟不推理，或直接重启机器后不启 AI 引擎）。
2. 开始录屏，进入首页首屏。
3. 检查点：①输入条**可见可聚焦**，placeholder 显示「星伴引擎休眠中——输入将唤醒（约 30s）或直接使用下方能力胶囊」语义；②发送钮呈「唤醒引擎」态，点击有显式加载反馈且可取消；③四枚能力胶囊可点击走表单路径（不依赖 AI）；④整个首屏无禁止态无解释的死控件。

## 录屏三：纯键盘完成「建一个爬取任务」

1. 服务核心 + Flutter 端就绪，**全程不碰鼠标**，开始录屏。
2. 键盘剧本：`Ctrl+1` 回首页 → 快捷键聚焦输入条（或 Tab 序抵达）→ 输入「帮我爬取 https://cn.vuejs.org/guide/introduction.html 转成 Markdown」→ `Ctrl+Enter` 发送 → 指令卡确认（Enter 执行）→ `Ctrl+4`（任务页）看进度 → `Ctrl+`` 打开日志面板 → `Esc` 逐层关闭 → 任务完成后横幅「打开产物目录」。
3. 检查点：每一步焦点位置可预测（FocusTraversalGroup 分区）；Esc 逐层退出语义正确；全程无「必须点一下鼠标」的断点。

## 执行纪律

- 三条录屏失败即记 issue（标注复现步骤），不静默重录蒙混；界面如与本页描述不符，以实际界面为准回填本页描述（本页是指引不是规格）。
- 录屏文件体积控制：MP4/H.264、1080p、≤60s/条；只入库记录表与关键帧截图（视频本体走 Release 附件或本地留存，不入 git）。
